# FFT 自检

## 运行

```bash
source /data/Xilinx/2026.1/Vivado/settings64.sh
python3 scripts/run_all.py --ip-type xfft --all
```

常用配置有 4 组。扩展配置有 1344 组，只做静态参数检查，不默认全部运行。

## 检查内容

当前接入单通道、固定点数、非 SSR 的定点 FFT。点数为 8 至 256，输入和相位因子
位宽为 8 至 34。配置覆盖正变换、逆变换、自然顺序、位反转顺序，以及流水、
Radix-2、Radix-2 Lite 和 Radix-4 三类突发实现。

Python 按 DFT 定义独立计算结果。输入包括全零、实部和虚部冲激、常量、交替符号、
四相复数序列和移位冲激。另把参数生成器给出的每个边界值放到冲激首项，保证实际
送入 DUT。所选序列的输出都是整数，因此逐位比较，不使用误差范围，也不调用厂商
位精确模型。

testbench 先通过 `s_axis_config` 发送正反变换配置，再通过 `s_axis_data` 发送完整帧。
输出检查复数值、`XK_INDEX`、`TLAST`、顺序、回压保持以及输入 `TLAST` 错误事件。
复数实部放在 `TDATA` 低位，虚部放在高一条字节对齐通道中。两项都是有符号定点数，
不足整字节的高位按符号扩展。

## 限制

当前没有测试缩放表、块浮点、运行时点数、循环前缀、多通道、SSR、浮点格式和
运行中复位。普通随机复数序列会受旋转因子量化影响，需要分级定点参考后才能严格
比较，不能简单加大容差。本轮只运行常用配置，不表示 1344 组扩展配置都通过 Vivado。

2026.1 全量运行中的 4 组配置、12 个阶段全部通过，
见[运行记录](../../experiments/vivado_2026_full_regression.md)。

接口和数值规则依据 [PG109](https://docs.amd.com/r/en-US/pg109-xfft/Core-Overview)。
