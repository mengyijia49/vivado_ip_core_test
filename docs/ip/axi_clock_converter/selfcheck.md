# AXI Clock Converter 自检

本模块测试 `axi_clock_converter:2.1` 的异步时钟模式。输入时钟固定为 10 ns，输出时钟
覆盖 6、10、14、20 和 30 ns，同步级数覆盖 2 至 8。

testbench 分别发送 AW、W、B、AR、R 五个通道。每条记录都检查 ID、地址、突发属性、
数据、字节使能、响应和 USER 字段。接收端会故意暂时拉低 READY，检查 VALID 和负载在
回压期间保持不变。Python 参考只规定各通道收到的内容和顺序，不假定跨时钟需要固定几拍。

当前每次只让一个通道传输，尚未检查五个通道同时满负荷运行，也没有在传输中间复位。
这些场景后续仍可加入，当前通过不能代替它们。
