# AXI INTC：写入一个中断状态时，已有的状态被清掉

Vivado 2026.1 中，向 ISR 写 0 后，原有的中断位从 1 变成了 0；
写另一个中断位时，旧位也消失了。独立 VHDL 和整批自检都留下了记录。

## 中断控制器有什么用

外设需要处理器处理事情时，会发出中断请求。例如一笔数据收完了，
外设通知处理器来读取。AXI INTC 把多路中断集中起来，记录哪些请求正在等待处理，
再用一根 `IRQ` 信号通知处理器。

寄存器是软件可读写的控制或状态存储位置。本页会用到：

| 名称 | 含义 |
| --- | --- |
| ISR | 记录哪些中断有效，每个二进制位对应一路 |
| IER | 每路中断是否允许影响 IRQ |
| IAR | 确认/清除指定的中断 |
| MER 中的 ME | IRQ 的总使能 |
| MER 中的 HIE | 是否启用真实硬件中断输入；设为 1 后，通常要复位才能清回 0 |

“第 0 位”是二进制最右边的一位。例如 ISR 为 `001`，表示第 0 路有效；
为 `011`，表示第 0、1 路都有效。

## 写 ISR 应该发生什么

[PG099 第 15–16 页](https://docs.amd.com/v/u/en-US/pg099-axi-intc)
规定，在允许软件写入的位上，写 1 触发对应中断，写 0 不起作用。
因此，在没有其他清除动作的这段测试中，预期可以写成：

```text
写入后的 ISR = 原有 ISR 按位 OR 本次写入值

原有 001，写 000：应该仍为 001
原有 001，写 010：应该变为 011
```

OR 是逐位“或”：两个对应位只要有一个为 1，结果就是 1。
所以第二种操作应该增加一个有效中断，而不是删掉旧中断。

## 独立 VHDL 的参数和操作

IP 修订号为 23，配置为 1 路硬件中断、2 路专用软件中断；
硬件输入设为上升沿触发、同步输入，不启用 ILR 优先级阈值功能。
实际硬件输入一直为 0，本例靠寄存器写入产生中断。

这里特意测试了两个运行状态，它们使用同一个 IP 配置：

| HIE 状态 | 哪些位可以由软件写 1 触发 |
| --- | --- |
| HIE=0 | 允许软件向硬件中断对应位写入，便于启动时测试 |
| HIE=1 | 硬件中断对应位不再供软件触发；专用软件中断位仍可写 |

因此，即使某个配置的专用软件中断数为 0，HIE=0 时仍可以测试 ISR 写入。

每轮先复位，再开启所需中断和 ME。记录如下，表中的数字为十进制：

| 运行状态 | 先建立的旧 ISR | 接着写 ISR | 应读回 | 实测 |
| --- | ---: | ---: | ---: | ---: |
| HIE=0 | 1，即 `001` | 0 | 1 | 0 |
| HIE=0 | 1，即 `001` | 2，即 `010` | 3，即 `011` | 2 |
| HIE=1 | 2，即 `010` | 0 | 2 | 0 |
| HIE=1 | 2，即 `010` | 4，即 `100` | 6，即 `110` | 4 |

写 0 的两次，IRQ 也从应有的有效状态变成无效。
现象像“用新值覆盖整个可写字段”，但这是根据读回作出的判断，
还不是已经确定的内部实现原因。

## 整批自检里的全部 12 组配置

下面各组首次失败都在 `isr_preservation_hie0_bit0` 测试段，
意思是“硬件输入尚未启用时，检查第 0 位的旧状态是否保留”。

| 配置 | 硬件输入 | 软件中断数 | 异步位掩码 | 同步级数 | IRQ 极性 / 关闭的可选项 |
| --- | --- | ---: | --- | ---: | --- |
| `intc_rise1_sw2` | 1 路上升沿 | 2 | 0 | 2 | 高有效 |
| `intc_fall1` | 1 路下降沿 | 0 | 0 | 2 | 高有效 |
| `intc_high1` | 1 路高电平 | 0 | 0 | 2 | 高有效 |
| `intc_low1` | 1 路低电平 | 0 | 0 | 2 | 高有效 |
| `intc_mixed4_sw2` | 4 路混合 | 2 | 0 | 2 | 高有效 |
| `intc_mixed4_lowirq` | 4 路混合 | 2 | `0xF` | 2 | 低有效 |
| `intc_mixed4_minimal` | 4 路混合 | 0 | 0 | 2 | 高有效；关 CIE、ILR、IPR、IVR、SIE |
| `intc_mixed8_sw24_ff7` | 8 路混合 | 24 | `0xFF` | 7 | 高有效 |
| `intc_mixed16_ff0` | 16 路混合 | 1 | `0xFFFF` | 0 | 高有效 |
| `intc_rise31_sw1` | 31 路上升沿 | 1 | `0x55555555` | 3 | 高有效；关 CIE |
| `intc_mixed32` | 32 路混合 | 0 | 0 | 2 | 高有效；关 SIE |
| `intc_rise1_sw31_lowirq` | 1 路上升沿 | 31 | `0x1` | 7 | 低有效；关 ILR |

“混合”按上升沿、高电平、下降沿、低电平循环排列。
上升沿是 0 变 1 的时刻；高电平则是信号处于 1 的状态。另两种相反。
异步掩码中某一位为 1，表示对应输入按异步信号处理；
同步级数是为同步输入使用的寄存器级数。高有效 IRQ 用 1 报警，低有效用 0。

可选寄存器除表中写明关闭的以外都开启：

| 可选项 | 作用 |
| --- | --- |
| SIE / CIE | 便捷地开启/关闭指定中断，不必改写整个 IER |
| IPR | 查看哪些中断既有效又已使能 |
| IVR | 给出当前优先处理的中断编号 |
| ILR | 用优先级阈值控制哪些中断可被处理 |

12 组都有同一测试段的失败证据，但没有逐组做出上述四种独立读回。
它们说明受影响的配置可能不止一种，还不能证明有 12 个不同原因。
