# 移位寄存器自检

配置位于 `configs/ip/shift_register/`，IP 为 `c_shift_ram:12.0`。

- `width`：1 至 256 位。
- `depth`：1 至 1024，指有效移位次数。
- `clock_enable`：是否添加 CE。

当前只支持固定长度，初始数据全零，保留末级寄存器，不启用同步清零。
每个有效上升沿把 D 放入队列；第 depth 次有效移位后可在 Q 看到该输入。
CE=0 时队列和输出保持。深度 1 单独处理，不能多算一级延迟。

定向序列包含脉冲和足够长的后续零；测试结尾继续运行 depth 个有效周期，
避免深队列的尾部输入还没出来就结束检查。
扫描覆盖 16、32、64、128 等深度的前后边界。

依据 [PG122](https://docs.amd.com/v/u/en-US/pg122-c-shift-ram)。
可变地址和同步控制尚未接入；尤其不能假定 SCLR 会清空内部全部 RAM。
