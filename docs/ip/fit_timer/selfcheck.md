# FIT Timer 自检

本模块测试 `fit_timer:2.0`。它没有寄存器总线，只按配置的时钟数周期性输出一个
`Interrupt` 脉冲。

独立 Python 计划根据 `no_clocks` 和千分比 `inaccuracy` 算出允许的周期范围。行为
testbench 检查复位期间中断为低、输出没有未知值、脉冲宽度为一个时钟，以及复位前后
连续脉冲的周期。复位保持 20 个时钟，满足该 IP 的 SRL16 实现要求。

常用配置覆盖 3、128 和 1009 个时钟，包含高低两种复位极性、精确周期、允许误差、
SRL16 链和普通计数器。扩展配置有 96 组，周期从 3 到 65521 个时钟。周期较大的配置
行为仿真时间也会明显增加。

当前不检查 FPGA 实际时钟频率、温漂或板级时间，只检查行为模型中的时钟周期数。
测试不运行综合、实现或网表仿真。

Vivado 2026.1 运行了 4 组常用配置，12 个阶段均为 `PASS`，
见[全量报告](../../experiments/vivado_2026_full_regression.md)。

参数和复位要求以 AMD PG110 及当前 Vivado 组件描述为准。
