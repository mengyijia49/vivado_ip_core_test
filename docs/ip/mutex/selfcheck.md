# Mutex 自检范围

## 已检查内容

Vivado 2026.1 中使用 `xilinx.com:ip:mutex:2.1`。每个配置有 2、4 或 8 个
AXI4-Lite 接口，共享 1 至 32 个互斥单元。所有接口在当前测试中使用同一个时钟。

testbench 会检查：

- 单互斥单元配置复位后清零；多单元配置先显式初始化被测地址；
- 一个端口获取锁后，其他端口能读到相同状态；
- 非所有者不能改写或释放锁；
- 未启用硬件保护时，相同 CPUID 可从另一端口释放锁；
- 启用硬件保护时，另一端口即使使用相同 CPUID 也不能释放锁；
- USER 寄存器在各端口之间共享；
- 第一个和最后一个互斥单元互不影响；
- 多个端口同时申请同一把锁时，最低编号接口获得锁；
- AXI 读写响应在回压期间保持不变。

数值判断由 `MutexModel` 独立维护锁状态、CPUID、接口身份和 USER 寄存器，
testbench 不读取 Vivado 生成源码来计算期望值。

2026.1 全量运行中的 4 组配置、12 个阶段全部通过，
见[运行记录](../../experiments/vivado_2026_full_regression.md)。

## 当前限制

多单元配置使用分布式 RAM，生成模型没有清空整个存储阵列的复位端口，因此测试不假定
其上电内容或复位后内容为零，只检查复位后总线恢复并可重新初始化。

当前没有测试异步 AXI 时钟、非完整 `WSTRB` 和保留地址。异步模式需要每个端口使用
不同频率和相位，并单独检查跨时钟域延迟，不能把同步测试结果当成异步模式结论。
