## 模型修正

首轮编号 `2026-09-15_10-13-32_UTC+0800_a3d0c9f9` 失败，原始报告和输入输出继续保留。
全部定向操作通过后，随机序列出现捕获模式回绕的脉冲累计数差异；
计数、加载值和中断比较没有差异。

参考模型错误地把 GENT 输出限制在生成模式。按
[PG079 端口说明](https://docs.amd.com/r/en-US/pg079-axi-timer/Port-Descriptions)，
生成输出按计数回绕触发，中断则由模式选择回绕事件或捕获事件。
修正模型后，补了捕获模式跨边界且启用/禁用 GENT 的定向用例。
没有删除这个输入，也没有屏蔽脉冲字段；此失败属于参考模型遗漏，不计作 IP bug。

独立 VHDL 的暂停、重装载和捕获观察见[时序探测](../ip/axi_timer/interface_probe.md)。
详细覆盖范围和未接入项见[Timer 自检](../ip/axi_timer/selfcheck.md)。
