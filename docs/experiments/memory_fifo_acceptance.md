## 排除的参考模型问题

首轮 FIFO 模型错误地把同步复位周期的 overflow、underflow 一律清零。
[PG057](https://docs.amd.com/v/u/en-US/pg057-fifo-generator) 第 135 页说明它们仍取决于请求和满空状态。
已按规范修正，并加入空时复位加读请求、满时复位加写请求的检查。
原日志和失败报告保留。这不是已发现的 IP bug。
