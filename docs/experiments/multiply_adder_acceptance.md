## 检查器与限制

常规测试 186 项，171 项通过，15 项真实工具测试默认跳过。
另显式运行 3 项乘加 XSim 检查：正确对照、只破坏 PCOUT、只颠倒减法方向。
结果均符合预期。人工错误只证明检查器能报错，不算真实 IP bug。

接入时发现本机内部映射编号 1 表示交换输入的单 DSP，不是多 DSP；已修正模型解释。
这是框架开发问题，不是 IP bug。数值独立计算，路径延迟依赖本机 IP 参数函数，
并保存在 `vectors/ip_timing.json` 中，随运行归档。
具体方法和范围见[乘加自检](../ip/multiply_adder/selfcheck.md)。
