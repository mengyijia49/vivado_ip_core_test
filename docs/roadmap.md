# 后续工作

## 已有能力

- 64 类 IP 的创建和自检接口，以及按 IP 分开的参数扫描配置。
- 定向随机、覆盖引导、穷举三种输入选择策略。
- 多种子、系统边界、输入乱序和时序扰动。
- 按时间保存工程、日志、报告、源码和输入输出，支持核对后续跑。
- 自检失败后扫描全部已有输出，按阶段、字段和流路由汇总不同位置的差异。
- 单元测试、真实 XSim 故障注入测试，以及不依赖 Vivado 的 CI 配置。

具体检查方法见[验收清单](framework_acceptance.md)。

## 接下来做什么

1. 核对累加器 CE/BYPASS、复数乘法长延迟、TMR 锁步展开和 GPIO 寄存器差异。
   INTC 已接入状态模型和参数矩阵，ISR 与 ME 异常有独立复现；继续补 Fast、级联和启动边界。
   GPIO 和 Timer 已接入 AXI-Lite，Timer 继续补 PWM、级联及不停计数时的总线访问。
   静态流路由已经接入，继续补动态路由、部分连接、仲裁授权次序和非法目的地址。
   位宽转换已有部分字节检查，其他流接口仍需补充；还需运行中复位和更多时钟关系。
   原生 FIFO 已支持标准读和 FWFT，继续补异宽模式；块存储器继续补异宽及独立时钟。
   TMR 继续补两沿之间的保持检查；ECC 先解决公开校验位约定的问题。
   旧版拼接的 128 路模型异常已独立复现，继续核查维护范围，不将它冒充新版缺陷。
   Inline 拼接、截取、常量、向量逻辑和归约逻辑已接入，继续检查更宽数据和组合边界。
   逐周期后端已改进超宽二进制文本读取，
   其他后端的宽数据路径还需分别检查。
   浮点已接入转换、平方根、比较、加减、乘除、融合乘加/减、倒数、倒数平方根、
   指数和自然对数，继续补运行中复位和其他运算。
   DDS 已接入固定相位发生器，继续补可编程配置通道、正弦查表和多通道。
   Processor System Reset 已接入过滤窗口、极性、锁定丢失和分阶段释放检查。
   Clocking Wizard 已接入 MMCM/PLL 的周期、占空比、锁定和复位恢复检查；
   模拟抖动、动态重配置和多输出相位仍未覆盖。
   CIC Compiler 已接入固定倍率、单通道、全精度抽取和插值；
   继续补可编程倍率、多通道、截位和 ACLKEN。
   I2S Transmitter 已接入主模式，检查 AXI-Lite 配置、AXI4-Stream 声道路由、
   串行数据、LR 槽宽和时钟分频；从模式、中断和运行中复位尚未覆盖。
   AXI UART Lite 已接入串行回接、字符宽度、校验、FIFO、状态和总线响应；
   继续补独立外部接收错误注入、发送 FIFO 满和中断脉冲计数。
   卷积编码器已接入非打孔模式、约束长度、多项式和 1/2 至 1/7 输出率；
   继续补打孔、双路输出、TLAST 事件和 ACLKEN。
   FFT 已接入单通道无缩放定点模式；继续补缩放表、块浮点、运行时点数、
   循环前缀、多通道和普通复数序列的分级定点参考。
   AXI BRAM Controller 已接入 AXI4-Lite 内部存储；继续补 AXI4 burst、窄传输、ID 和 ECC。
   LMB BRAM Interface Controller 已接入单 LMB 标准协议；继续补多主仲裁和 ECC。
   AXI Timebase Watchdog 已接入旧版模式；继续补 Window WDT、第二序列计时器和失败计数。
   FIT Timer 已接入周期、允许误差和复位恢复检查；更长周期按需单独运行。
   Mutex 已接入同步时钟下 2、4、8 个 AXI 端口的共享状态和仲裁检查；
   异步接口时钟仍需单独接入。
   Mailbox 已接入同步双 AXI4-Lite 的双向 FIFO、错误、清除和阈值中断检查；
   AXI4-Stream 和异步时钟模式仍需单独接入。
   Util FF 已接入四种触发器和两种锁存器；继续补时钟反相和多级配置。
   AXI-to-APB Bridge 已接入 APB4 的多窗口路由、等待、字节写和错误映射；
   APB3 模式和非连续地址窗口尚未覆盖。
   AXI4-Stream FIFO 已接入 AXI4-Lite 控制和同步收发流回接；
   AXI4、cut-through、ECC、发送控制流及更多侧带尚未覆盖。
   TMR Injector 已接入 32 位 Standard LMB 的一次性指令替换和保护检查；
   TMR Manager、Frequency LMB 和系统级 MicroBlaze 执行尚未覆盖。
   双精度低延迟乘法已有独立数值差异，继续核对其他版本和官方记录。
   大矩阵已逐项读取并用临时索引去重；后续继续降低完整扫描耗时，不绕过配置校验。
2. 接入研究算法。沿用现有策略接口，固定预算、种子和 IP 配置，与基线比较。
3. 长期运行探索配置。记录异常，复现后排除环境、脚本和参考模型问题。
4. 补充输入缩减和根因去重，减少人工排查；这两项目前还没有实现。
   已有差异分组只能提示排查位置，不能直接当作独立根因。
5. 整理论文实验：确认的独立 bug、发现时间、输入数量、误报和重复触发情况。

使用者计划测试一至两个月、寻找至少 5 个独立 bug。这是实验目标，
不是当前结果，也不能通过增加随机数量保证达到。

每一步都应保留现有可运行流程，并更新对应测试和文档。
后续扩展仍只做行为仿真，不增加综合、实现、网表仿真和时序仿真阶段。
