# 后续工作

## 已有能力

- Divider、Multiplier 的多参数创建和数值自检。
- 定向随机、覆盖引导、穷举三种输入选择策略。
- 多种子、系统边界、输入乱序和时序扰动。
- 按时间保存工程、日志、报告、源码和输入输出，支持核对后续跑。
- 单元测试、真实 XSim 故障注入测试，以及不依赖 Vivado 的 CI 配置。

具体检查方法见[验收清单](framework_acceptance.md)。

## 接下来做什么

1. 扩展 IP 和接口模式。每次增加一种，先明确参数、协议和预期结果，再写插件和测试。
2. 接入研究算法。沿用现有策略接口，固定预算、种子和 IP 配置，与基线比较。
3. 长期运行探索配置。记录异常，复现后排除环境、脚本和参考模型问题。
4. 补充输入缩减和根因去重，减少人工排查；这两项目前还没有实现。
5. 整理论文实验：确认的独立 bug、发现时间、输入数量、误报和重复触发情况。

使用者计划测试一至两个月、寻找至少 5 个独立 bug。这是实验目标，
不是当前结果，也不能通过增加随机数量保证达到。

每一步都应保留现有可运行流程，并更新对应测试和文档。
